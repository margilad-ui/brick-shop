# BRICK Shop · אפיון מערכת המלאי והחנות

**עודכן:** 15 באוקטובר 2026, 20:30

## מה זה

מערכת אחת, שני פנים, בסיס נתונים אחד:

1. **משרד אחורי** (אחרי כניסה, רק גילעד): ספירה ורישום מלאי מול המדף בטלפון, ניהול וטבלה במחשב.
2. **BRICK Shop** (פתוח לכולם): חנות מעוצבת לפי ספר המותג של BRICK HOUSE, עם ג'ואי כדמות שמובילה את החוויה. עגלה ותהליך רכישה מלא שמסתיים בביט או בוואטסאפ (בלי ספק סליקה בשלב זה). מצב דמו עד שהספירה מסתיימת.

הרעיון המרכזי: לא מקלידים נתונים. כל קופסה נושאת מספר סט (5 ספרות בחזית) וברקוד EAN (מאחור). שניהם מובילים לרשומה מלאה בקטלוג (Brickset). הרישום הוא: מה, כמה, איפה.

## מודל הנתונים

### ניהול (קריאה וכתיבה רק לבעלים, RLS דרך `bs_is_owner()`)

- **bs_catalog**: רשומה לכל סט (מפתח `set_num` כמו `76388-1`). נמשכת מ Brickset ונשמרת. שדות: מספר, שם, שנה, סדרה, תת סדרה, חלקים, מיניפיגורות, גיל, אריזה, תאריכי השקה ופרישה, מחירי מחירון (US, UK, DE, CA), תמונה, ברקודים EAN ו UPC, מידות (`dims`: width, height, depth בס"מ, weight), מידות המודל, דירוג, תגיות, תיאור באנגלית, תיאור בעברית (בקול של ג'ואי, נכתב פעם אחת), brickset_id, raw. 8,448 סטים (2018 עד 2026).
- **bs_items**: שורת מלאי. סוג (set, polybag, gear, parts, other), קישור לקטלוג, שם מותאם לפריטים שאינם בקטלוג, מיקום, כמות, מצב (sealed, open, built), סטטוס (sale, personal, hold, sold), מחיר ומקור המחיר, תגיות, הערות, תמונה.
- **bs_zones**: אזורים (קיר, ארון, חדר, מחסן): קוד קצר (`B`), שם, צבע (red, blue, green, yellow, cocoa, oak, ink, stone), site, סדר.
- **bs_locations**: מדפים, קופסאות, ארונות, מגירות, תאים (`kind`), קוד מלא `B3` = אזור + מספר, תווית ("קיר B · מדף 3"), צבע, `active`. היום: A1 עד A6, B1 עד B6, C1 עד C6, D1 עד D6, P1 עד P6 (Polybags). **לא תואם למדפים בפועל** (A: 5, B: 3, C: 7, ראו 05).
- **bs_movements**: כל שינוי כמות (הוספה, מכירה, העברה, תיקון).
- **bs_settings**: `usd_ils` (3.1), `retired_multiplier` (1.2), `vat_included` (true), `shop_demo` (true), `shop_whatsapp` (972525000553), `shop_bit_phone` (0525000553).
- **bs_secrets**: מפתחות API (BRICKSET_API_KEY). RLS בלי מדיניות, קריאה רק דרך service role.
- **bs_owners**: מי מורשה. טריגר על `auth.users` רושם אוטומטית כבעלים את `mar.gilad@gmail.com`.
- **bs_inventory** (view): פריטים עם נתוני הקטלוג והאזור, כולל `retired` מחושב.
- **bs_asset_jobs**: תור עבודות לפונקציית `assets` (url, path, content_type, status, bytes, public_url, error). נכתב רק מ SQL.
- **bs_catalog_images**: set_num, brickset_id, images (jsonb של {image, thumb}), fetched_at. 75 ערכות, 1,032 תמונות רשמיות (Brickset getAdditionalImages). קריאה ציבורית.

### שכבת החנות (קריאה ציבורית, anon)

- **bs_shop** (view): פריטי bs_items בסטטוס sale עם כמות, מוצמדים לקטלוג.
- **bs_shop_demo** (view): ערכות דוגמה מהקטלוג: 3 לכל סדרה מובילה (20 סדרות) לפי דירוג, ובנוסף כל ערכה שיש לה רנדר קופסה. מחיר מחושב: rrp_us × usd_ils (× retired_multiplier לפרשו), מעוגל לעשרות. `demo = true`, id חדש בכל קריאה (האפליקציה משתמשת ב `demo-<set_num>`). 62 ערכות היום.
- **bs_shop_catalog** (view): רשומת קטלוג לדף מוצר (גם לערכה שאינה למכירה).
- **bs_shop_boxes** (view): מה יש ב Brickset לכל ערכה לפי שם הקובץ: `front` (Box1 או Box3, פנים שטוחות), `back` (Box5 או Box6), `prod` (boxprod, צילום מוצר). 13 פנים, 21 גבים.
- **bs_shop_box_art** (view): ערכות עם רנדרי קופסה מוכנים לווב (`spine_url`, `angle_url`), נגזר מ bs_asset_jobs על `boxes/web/`. 8 ערכות.
- **bs_shop_config()**: ההגדרות הציבוריות (shop_demo, shop_whatsapp, shop_bit_phone, usd_ils, vat_included).
- **bs_place_order(jsonb)**: security definer. שומרת הזמנה ב **bs_orders** (מספר רץ מ 1001 דרך `bs_order_seq`, שם, טלפון, יישוב, איסוף/משלוח, הערה, פריטים jsonb, סכום, ביט/וואטסאפ, סטטוס new/test, שפה) ומחזירה את המספר. קריאת הזמנות רק לבעלים.

## זרימות

**הוספה מול המדף (טלפון):** בוחרים מדף פעם אחת → מקלידים 5 ספרות או סורקים ברקוד → פונקציית `catalog` (lookup) מחזירה את הסט (מהקטלוג המקומי, ואם אין, מ Brickset ושומרת) → כרטיס לאישור עם "כבר במלאי: N" ומחיר מוצע → כמות, מצב, סטטוס → "הוסף" → שורה ב bs_items ותנועה ב bs_movements. ערימה זהה = שורה אחת עם כמות.

**פריט שאינו בקטלוג:** טופס קצר: שם, סוג, כמות. תמונה מהמצלמה עדיין לא.

**רשימה וטבלה:** חיפוש חופשי, סינון לפי סטטוס, מצב ייצור, כמות, נושא, קיר, תגיות. מיון. מגירה עם כל הפרטים לעריכה. ייצוא CSV.

**החנות:** רגע פתיחה (פעם ב 12 שעות) → דף הבית (הירו עם מדף קופסאות וג'ואי, חדרים, "ג'ואי בחר", עולמות, הבטחות) → כל הערכות (סינון, סדרה, מיון, חיפוש) או לאספנים (הכספת) → דף מוצר (גלריה רשמית, נתונים, ג'ואי על הערכה, תיאור, קשורים) → "הבאתי!" לעגלה → תהליך רכישה בשלושה שלבים → סיום: ביט (סכום, מספר, מספר הזמנה, כפתורי העתקה) או וואטסאפ (הודעה מוכנה), וההזמנה נשמרת.

**מכירה (עתיד, אבן דרך 2):** מסך הזמנות במשרד האחורי: סימון שולם ונשלח מוריד כמות ורושם תנועה. כשהכמות אפס הפריט נעלם מהחנות לבד.

## הארכיטקטורה

- **Supabase** (Postgres, Auth, Storage, Edge Functions, pg_net). אזור eu-central-1. משותף עם אפליקציה אחרת (tripaloo), מבודד ב RLS.
- **Edge Function `catalog`** (verify_jwt): `lookup` (מספר סט או ברקוד: קטלוג מקומי → Brickset getSets → שמירה), `sync` (שנה שלמה מ Brickset, עד 500 לעמוד), `usage`.
- **Edge Function `assets`** (verify_jwt=false, גרסה 5): מעבדת רק שורות pending מ bs_asset_jobs (10 לקריאה). סוגים: mime (העתקה מכתובת מותרת ל Storage), `key` (ניקוי ירוק לשקיפות + חיתוך לתוכן, imagescript מ deno.land), `fit:<גובה>` (הקטנת PNG עם שקיפות), `brickset` (getAdditionalImages ל bs_catalog_images). מופעלת מ SQL: `bs_asset_import(url, path, type)` מוסיפה שורה ושולחת pg_net POST.
- **אפליקציה**: Vite + React + TypeScript, עברית RTL, PWA (vite-plugin-pwa, autoUpdate). `src/main.tsx` טוען את החנות כשהנתיב מתחיל ב `/brick-shop/shop`, אחרת את המשרד האחורי (שני bundles). סורק ברקוד: `BarcodeDetector` כשקיים, אחרת ZXing. החנות: ראוטר קטן משלה, מילון he/en, עגלה ב localStorage, רכיב `Clip` (וידאו ירוק → WebGL chroma key → canvas שקוף, עם נפילה לתמונה).
- **אירוח**: GitHub Pages דרך GitHub Actions, base `/brick-shop/`. `404.html` עותק של `index.html` כדי שקישורים עמוקים יעבדו (מחזיר 404 HTTP; חיסרון ל SEO ולתצוגות שיתוף, לכן Netlify על השולחן).
- **נכסים**: Supabase Storage, bucket ציבורי `bs-assets` (ראו 04). סרטוני ג'ואי על ירוק, 1080p, מנוקים בדפדפן. תמונות מנוקות בשרת.
- **אבטחה**: כניסה באימייל וסיסמה (משתמש אחד), הרשמה ראשונה בקוד 6 ספרות. RLS על כל הטבלאות. בדפדפן רק המפתח הציבורי של Supabase. הפונקציה `assets` פתוחה אבל לא עושה כלום בלי שורה בתור.
