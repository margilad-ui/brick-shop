## מה זה, במשפט

מערכת מלאי וחנות לאוסף הלגו של גילעד (מאות קופסאות חדשות, Polybags, ציוד). בסיס נתונים אחד, שני פנים: משרד אחורי לספירה וניהול (קיים, באוויר), ו BRICK Shop, חנות מעוצבת ללקוחות לפי המותג BRICK HOUSE (באוויר מ 15.10 בגרסה ראשונה, בכתובת /shop, עם ג'ואי כמארח).

הרעיון המרכזי: לא מקלידים נתונים. מספר סט (5 ספרות בחזית הקופסה) או ברקוד EAN (מאחור) מובילים לרשומה מלאה בקטלוג Brickset. הרישום הוא רק: מה, כמה, איפה.
