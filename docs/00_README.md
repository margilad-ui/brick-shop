## מה זה, במשפט

מערכת מלאי וחנות לאוסף הלגו של גילעד (מאות קופסאות חדשות, Polybags, ציוד). בסיס נתונים אחד, שני פנים: משרד אחורי לספירה וניהול (באוויר מ 14.10), ו BRICK Shop, חנות מעוצבת ללקוחות לפי המותג BRICK HOUSE, עם ג'ואי, כלב הבית, כדמות שמובילה את כל החוויה (באוויר מ 15.10 בכתובת /shop).

הרעיון המרכזי: לא מקלידים נתונים. מספר סט (5 ספרות בחזית הקופסה) או ברקוד EAN (מאחור) מובילים לרשומה מלאה בקטלוג Brickset. הרישום הוא רק: מה, כמה, איפה.
